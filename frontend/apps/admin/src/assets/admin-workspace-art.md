# Arte de cabeceras de XAMUKO Admin

Ilustración sobria de archivo y control administrativo, creada para la paleta #0F172A, #7B3FFB, #2563EB, #F8FAFC y el acento #22C55E. No contiene texto, cifras de negocio ni datos simulados. Todo el contenido de la aplicación es HTML/React.

Fuente generada de 1672 × 941 px. Exportación 4K WebP de 3840 × 2160 mediante remuestreo, no captura nativa 4K; variante de 960 × 540 px para entrega responsive. Recurso compartido por las cabeceras de las áreas administrativas; títulos, iconos y textos varían por sección.
